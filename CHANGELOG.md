# Changelog

## 8.9.4 - Phase 9e: alphabetical home, theme without flash, sound stops on Back, smoother open / close
- **Alphabetical.** Home "All modules" and search results are sorted A-Z by the name on the card (`alpha()`, locale-aware). The Roadmap view keeps the learning order; Recents stays most-recent first.
- **Sound stops when you leave a module.** perf-guard used to park only `requestAnimationFrame`; Web Audio kept playing in the hidden iframe (exhaustsystem, starting-system, lighting). The controller injected into every module now tracks each `AudioContext`, routes it through one gain node, fades it out (about 30 ms) and suspends it on `perf-pause`; it resumes (fade in) on `perf-resume`. A `resume()` the module asks for while it is parked is remembered, not honoured. No module page changed. Also cancels speech synthesis. Closing no longer waits for the slide: `.active` is removed at once, the picture stays up through `.leaving`.
- **Theme.** (1) The shell sets the theme class in a tiny script in `<head>` (saved choice, else the OS), so light users no longer see a dark frame at start. (2) A module's document gets `light-theme` the moment it exists, and its iframe stays invisible behind a spinner until the module reports ready and has been themed, so there is no dark-to-light flash on first open. (3) The OS theme is only saved once the person picks one themselves (before, any view toggle froze the detected theme), and until then the app follows OS changes live.
- **Smoothness.** (1) A module that is not loaded yet starts loading when the slide ends, so script compile and WebGL set-up no longer compete with the animation; a spinner in the module's accent colour shows meanwhile. (2) The home screen no longer animates a full-screen `blur()` while it recedes (opacity + scale only). (3) The home grid is rebuilt while it is hidden (not at the start of the slide-out) and keeps its scroll position (it used to jump to the top after Back). (4) The module stays visible while it slides away (it used to blank at once).
- Cache `autolab-v8.9.4`.

## 6.1.0
- Fixed label wobble in all modules except cooling.
